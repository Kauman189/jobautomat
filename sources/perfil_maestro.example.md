## 1. Reading instructions and scope

This document gathers the information available in the project: the CV versions provided by Jane, the previous CV kept as a reference, and the design screenshots reviewed. It is not an independent audit of titles, contracts, jobs, languages or results. "Documented" means a data point appears in a reviewed source, not that an institution or company has certified it.

The newest CVs are the main reference. The previous CV is kept as background and for data that is not repeated, with clear warnings. A data point that disappears from the new CV is neither automatically false nor automatically current.

No research has been done on Jane's live website, her employers, job postings, salary markets, international legal conditions or LinkedIn/MCP integration availability. Domains are transcribed from the sources; this file does not prove they are online. This file does not certify work or residence permits.

## 2. Evidence tags

| Tag | Meaning | Bot usage |
|---|---|---|
| `DOC` | Data explicit in a reviewed CV. | May be used attributed to the profile/CV, respecting validity and limits. |
| `VIS` | Element actually visible in a screenshot. | Describes the observed material; it does not prove launch, sole authorship or results. |
| `USR` | Direct statement by Jane in the history or the current request. | Treat as self-declaration; do not turn it into external validation. |
| `TER` | Message from a third party copied by the user. | Describes what the third party communicated, not Jane's skills or a signed contract. |
| `INF` | Reasonable interpretation from evidence. | Useful for internal search; do not state it as a biographical fact. |
| `PEND` | Missing, ambiguous, time-sensitive or contradictory data. | Leave empty, mark pending or ask for the data if it blocks a concrete action. |
| `PROP` | Operating rule or proposal created for this bot. | Apply as a proposed working criterion; do not attribute it as a historical user preference. |
| `HIST` | Data from an earlier source that must be kept with context. | Does not automatically replace new information. |

No invented confidence percentages. The same statement can be `DOC` and still need a further check: for example, "English C1" appears in the CV, but no language certificate has been seen.
